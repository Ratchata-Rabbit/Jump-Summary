# HTML

สร้างไฟล์ `.html` ไฟล์เดียว (self-contained) จากเนื้อหา Markdown โดยใช้หน้าตาจาก `template.html` ในโฟลเดอร์เดียวกับไฟล์นี้

## เลือกต้นฉบับ
- ผู้ใช้ระบุไฟล์ (เช่น `/html HANDOFF.md`) → ใช้ไฟล์นั้น
- ไม่ระบุ → ใช้ไฟล์ `.md` ที่เพิ่งสร้าง/พูดถึงล่าสุดในแชท (มักเป็น `HANDOFF.md`)
- ไม่มีไฟล์เลย → ใช้เนื้อหาที่เพิ่งสรุปให้ผู้ใช้ในแชท
- ถ้ายังกำกวม ถามสั้นๆ ข้อเดียวว่าจะแปลงอะไร

## ขั้นตอน
1. อ่าน `template.html` แล้วคัดลอกโครงทั้งหมด (CSS + script) ไปใช้
2. แปลง Markdown → HTML เอง ให้ครบทุกส่วน **ไม่ตัด ไม่สรุปย่อ ไม่เพิ่มข้อมูลที่ไม่มีในต้นฉบับ**
   - หัวข้อ `#` → `<h1>` (ใส่ใน `<header>`), `##` → `<h2 id="...">`, `###` → `<h3>`
   - ตาราง → `<table>` ภายใน `<div class="table-wrap">`
   - code block → `<pre><code class="lang-xxx">` (escape `<` `>` `&`) — script ใน template จะเติมปุ่ม Copy ให้เอง
   - `- [x]` / `- [ ]` → `<li class="task done">` / `<li class="task">` (ใน `<ul class="tasks">`)
   - ลิงก์ → `<a href>` เปิดแท็บใหม่ (`target="_blank" rel="noopener"`)
   - บรรทัดที่ขึ้นต้นด้วย ⚠️ หรืออยู่ในหัวข้อ "ด่วน" → ห่อด้วย `<div class="callout warn">`
3. ตั้ง `<title>` = หัวข้อแรกของเอกสาร และใส่วันที่อัปเดต (ถ้ามี) ใน `<p class="meta">`
4. บันทึกเป็นชื่อเดียวกับต้นฉบับแต่นามสกุล `.html` ไว้ข้างไฟล์ต้นฉบับ (เช่น `HANDOFF.md` → `HANDOFF.html`) ถ้ามีไฟล์เดิม → เขียนทับ (เป็นไฟล์ที่ skill นี้สร้าง)
5. เปิดดูผลในเบราว์เซอร์ (ถ้ามี browser tool) เช็กว่าตาราง/โค้ด/ลิสต์แสดงครบ แล้วส่งไฟล์ให้ผู้ใช้ (SendUserFile ถ้ามี)
6. ตอบสั้นๆ: ลิงก์ไฟล์ + บอกว่าแปลงจากอะไร

## กฎ
- ไฟล์เดียวจบ: CSS/JS อยู่ในไฟล์ ใช้ได้แค่ Google Fonts จากภายนอก ไม่โหลด JS library อื่น
- รองรับมือถือ (ตารางเลื่อนแนวนอนได้), dark mode, และสั่งพิมพ์ได้ (ซ่อนปุ่ม/สารบัญตอนพิมพ์)
- **ห้ามเพิ่มข้อมูลส่วนบุคคลหรือ secret** ที่ไม่มีในต้นฉบับ ถ้าต้นฉบับมีชื่อคน/รหัสผ่าน/token ให้เตือนผู้ใช้ก่อนส่งต่อ
- ภาษาตามต้นฉบับ
