# Handoff

สร้างหรืออัปเดต `HANDOFF.md` ที่ root ของโปรเจกต์ ให้คนที่เปิดอ่าน (หรือ Claude ใน session ใหม่) ทำงานต่อได้ทันทีโดยไม่ต้องถามย้อน

## ขั้นตอน

1. **รวบรวมข้อมูลจริง ไม่เดา**
   - ประวัติใน conversation นี้: เป้าหมาย, การตัดสินใจของผู้ใช้, สิ่งที่ทำไปแล้ว, สิ่งที่ค้าง
   - ไฟล์ในโปรเจกต์ (โค้ด, config เช่น `.clasp.json`, `package.json`), `git status` / `git log` ถ้าเป็น git repo
   - memory ของโปรเจกต์ (ถ้ามี) และ `HANDOFF.md` เดิม (ถ้ามี → **อัปเดตไฟล์เดิม ห้ามสร้างไฟล์ซ้ำ**)
   - ถ้าเช็กสถานะจริงได้ง่าย (เช่น อ่านไฟล์, `clasp deployments`, `git status`) ให้เช็กก่อนเขียน อะไรที่เช็กไม่ได้ให้เขียนว่า "ยังไม่ได้ยืนยัน"

2. **เขียน `HANDOFF.md` ตามโครง `template.md`** (อยู่โฟลเดอร์เดียวกับไฟล์นี้)
   - ข้ามหัวข้อที่ไม่เกี่ยวกับโปรเจกต์ได้ แต่ **ต้องมีเสมอ**: เป้าหมาย, ลิงก์/ID, ทำเสร็จแล้ว, เหลือทำ, วิธีทำต่อบนเครื่องใหม่
   - หัวข้อ "เหลือทำ" แบ่งเป็น **ด่วน** (มีกำหนดเวลา/จะพังถ้าไม่ทำ) · **ต่อไป** · **เก็บกวาด** และระบุวันที่/เวลาแบบเต็มเสมอ (เช่น "ก่อน 09:30 วันที่ 15 ต.ค. 2026" ไม่ใช่ "พรุ่งนี้")
   - เขียนสูตร, ค่า config, คำสั่ง ให้ก็อบไปใช้ได้ตรงๆ ใน code block
   - ใส่ "ข้อควรระวัง" ที่เรียนรู้ระหว่างทำ (บั๊กที่เคยเจอ, สิ่งที่ห้ามแตะ, ขั้นตอนที่ลืมบ่อย)

3. **กฎความปลอดภัยของเนื้อหา**
   - **ห้ามใส่ข้อมูลส่วนบุคคล** (ชื่อพนักงาน/ลูกค้า, เบอร์, อีเมลคนอื่น, เลขบัตร) — ใช้จำนวนหรือ id แทน
   - **ห้ามใส่ secret** (password, API key, token, OAuth credential) — บอกแค่ว่าต้องไปเอาจากไหน
   - ลิงก์ไฟล์/โปรเจกต์ และ ID ใส่ได้ (คนเปิดได้ต้องมีสิทธิ์อยู่แล้ว)
   - ถ้ามีงานดึงข้อมูลจาก BigQuery ให้แนบ SQL ที่ใช้ไว้ด้วยเพื่อให้ตรวจสอบได้

4. **ภาษา**: เขียนด้วยภาษาเดียวกับที่ผู้ใช้คุย (ค่าเริ่มต้นไทย) ชื่อเทคนิค/ชื่อไฟล์/ชื่อคอลัมน์ใช้ตามของจริง

5. **ส่งมอบ**
   - บันทึก `HANDOFF.md` ที่ root โปรเจกต์ แล้วส่งไฟล์ให้ผู้ใช้ (SendUserFile ถ้ามี)
   - ตอบสั้นๆ: ลิงก์ไฟล์ + สรุปหัวข้อ + **รายการด่วน** ซ้ำอีกครั้งในข้อความ
   - ถ้าโปรเจกต์มี memory ให้แน่ใจว่า memory ไม่ขัดกับ HANDOFF ที่เพิ่งเขียน

## ตรวจก่อนส่ง
- [ ] มีวันที่อัปเดตบรรทัดแรก
- [ ] ทุกลิงก์/ID มาจากของจริงใน session หรือไฟล์ ไม่ได้แต่งขึ้น
- [ ] ไม่มีชื่อคน / secret
- [ ] "เหลือทำ" มีรายการด่วนพร้อมกำหนดเวลา (ถ้ามี)
- [ ] มีคำสั่งให้ทำต่อบนเครื่องใหม่ที่รันได้จริง
